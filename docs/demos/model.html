Workflow model

Every lifecycle in VERA as a state machine, drawn from one model (docs/design/shared/model/workflows.js) and checked by node docs/design/shared/model/check.js against itself, the shipped roles, the sidebar and the demo pages. A person's step names the permission it needs and the page it is offered on; the checker proves some role holds that permission and can open that page, and that the page's script has the action.

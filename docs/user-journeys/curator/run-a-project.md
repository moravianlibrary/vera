# Start a project and decide projects

**Who.** A curator: Kateřina Novotná, who may start projects, manage those she runs, and decide
any project.

**Goal.** "We got a grant for regional periodicals; set it up and let the team propose into it."

**Starting state.** No project for the grant exists.

## Steps

1. On *Projects* she starts a project with dates, a description and a page target.
   → It is Proposed; she is its manager and only member; it has its own intention, which is not
   listed on Intentions yet ([LC-PROJ-start](../../reference/lifecycles/project.md#lc-proj-start),
   [LC-PROJ-own-intention](../../reference/lifecycles/project.md#lc-proj-own-intention)).
2. She adds two colleagues and the *Periodicals Curators* group as members.
   → They can now propose into it
   ([LC-PROJ-propose-into](../../reference/lifecycles/project.md#lc-proj-propose-into)).
3. She opens Martin's Proposed project, *Hudebniny — NAKI III*, and approves it at *High* priority.
   → The impact is shown first. Its pending proposals are approved, except those with a copy or
   still being checked ([LC-PROJ-decide](../../reference/lifecycles/project.md#lc-proj-decide)).
4. Its manager, Martin, extends the approved project's end date.
   → Allowed; its intention's window follows and is recounted
   ([LC-PROJ-after-approval](../../reference/lifecycles/project.md#lc-proj-after-approval)).
